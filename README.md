# PetShop Amigo Animal - Fase 1

## Objetivo

Desenvolver a primeira versão de uma plataforma web para um petshop, utilizando HTML5, com o objetivo de apresentar produtos e serviços de forma organizada e acessível aos usuários. A Fase 1 tem como foco a construção da estrutura das páginas, a navegação entre conteúdos, a apresentação das categorias de produtos e as informações dos produtos e serviços oferecidos pelo estabelecimento.

## Tecnologias utilizadas

- HTML5
- Git
- GitHub
- GitHub Pages

Nesta fase não são utilizados CSS, Bootstrap ou JavaScript, conforme os requisitos do projeto.
